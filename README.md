# CRYPTOMEY — сканер сигналов MEXC Futures

Сервис на Python 3.12 (asyncio): следит за бессрочными USDT-фьючерсами MEXC, ищет рыночные события и присылает алерты **одному** пользователю в Telegram. Каждый сигнал сохраняется вместе с тем, что цена сделала после него, чтобы было видно, у каких сигналов есть преимущество после издержек.

Бот **не торгует** и не использует API-ключи.

Подробная документация появится по мере реализации фаз.

## Быстрый старт локально

```bash
python -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
DRY_RUN=1 .venv/bin/python -m scalpbot
.venv/bin/python -m pytest
```
